# Security policy

## Report a vulnerability in private

Do not report a vulnerability in a public issue.
Report it through GitHub's private vulnerability reporting, on the [new security advisory page](https://github.com/sukiyaki/octodns-netbox/security/advisories/new) of the repository.
Only you and the maintainers can see the report.

Include these in the report:

- The versions of octodns-netbox, octoDNS, pynetbox, and NetBox.
- The steps or the config that show the problem, without the token.
- What an attacker can do with it.

The project does not promise a time for a response or a fix.

## Only the latest release gets fixes

A fix comes out in a new release.
Older versions get no fixes, so upgrade to the latest release on [PyPI](https://pypi.org/project/octodns-netbox/).
